# 06. Интерфейс

Модуль: `src/ui/`

```text
src/ui/
├── mod.rs      объявления и реэкспорты
├── text.rs     Anchor, Label, TextCache
├── button.rs   Button, ButtonState
└── slider.rs   Slider, SliderState
```

Общая идея: **виджеты не знают о шрифтах**. Подпись — это готовая `Image`,
которую отрисовал вызывающий код. Поэтому в зависимостях библиотеки нет
SDL3_ttf, `ab_glyph` или `rusttype`.

Все координаты виджетов — **экранные**. `Draw` может нести камеру, но каждый
виджет снимает её на время своего `draw` через `Draw::screen_space`, чтобы
интерфейс не уезжал вместе с миром.

## `Anchor`

`src/ui/text.rs`. Определяет, какая точка текста стоит в позиции.

| Вариант | Точка |
|---|---|
| `Center` (по умолчанию) | Центр |
| `TopLeft` | Левый верхний угол |
| `Top` | Середина верхней грани |
| `TopRight` | Правый верхний угол |
| `Left` | Середина левой грани |
| `Right` | Середина правой грани |
| `BottomLeft` | Левый нижний угол |
| `Bottom` | Середина нижней грани |
| `BottomRight` | Правый нижний угол |

Приватная функция `place(anchor, position, size)` возвращает `Rect` (левый
верхний угол + размер). Она не трогает `Image`, поэтому правило размещения
тестируется без окна и шрифта.

## `Label<'a>`

```rust
pub struct Label<'a> {
    image: &'a Image,
    position: Vec2,
    anchor: Anchor,
}
```

`Label` — не виджет в привычном смысле, а «место для картинки». Картинка
заимствуется, а не клонируется.

| Метод | Что делает |
|---|---|
| `Label::new(&image)` | Текст в центре начала координат |
| `.at(x, y)` | Двигает выбранную якорную точку в `(x, y)` |
| `.anchored(anchor)` | Меняет якорь |
| `.size()` | Размер картинки |
| `.rect()` | Прямоугольник текста на экране |
| `.draw(d)` | Рисует текст, снимая камеру |

Пример:

```rust
let hello = frglib::Label::new(&image).at(360.0, 240.0);
let score = frglib::Label::new(&image)
    .anchored(frglib::Anchor::TopRight)
    .at(780.0, 20.0);
```

`Label::draw` создаёт `Object` по `rect()` и вызывает
`fill_textured_object`, то есть заливает текстуру на GPU каждый кадр. Для
неподвижного текста это нормально; для часто меняющегося лучше кеш или
`Texture`.

## `TextCache<R>`

```rust
pub struct TextCache<R> {
    images: HashMap<String, Image>,
    render: R,
}
```

Кеш отрендеренных строк. В цикле на 60 FPS одна и та же подпись иначе
растеризуется 60 раз в секунду.

| Метод | Что делает |
|---|---|
| `TextCache::new(render)` | `render: FnMut(&str) -> Result<Image, E>` |
| `keep(text)` | Рендерит строку, если её ещё нет |
| `get(text) -> &Image` | Готовая картинка; **паникует**, если строку не кешировали |
| `clear()` | Забывает всё |

Две операции нужны из-за заимствований:

- `keep` берёт `&mut self` и заполняет кеш до кадра;
- `get` берёт `&self` и позволяет держать несколько ссылок одновременно.

Поэтому `get` не возвращает `Result`: отсутствие строки — ошибка
программиста, а не сбой, который нужно обрабатывать в кадре.

Пример:

```rust
let mut cache = frglib::TextCache::new(|text: &str| {
    Ok(frglib::Image::from_surface(font.render(text).solid(white)?))
});

cache.keep("Очки: 120")?;

// внутри frame_with:
// let image = cache.get("Очки: 120");
```

## `Button`

Файл `src/ui/button.rs`.

```rust
pub struct Button {
    rect: Rect,
    idle: Color,
    hover: Color,
    pressed: Color,
    state: ButtonState,
}
```

| Состояние | Когда |
|---|---|
| `ButtonState::Idle` | Курсор не над кнопкой, кнопка не нажата |
| `ButtonState::Hover` | Курсор над кнопкой |
| `ButtonState::Pressed` | Кнопка удерживается |

| Метод | Что делает |
|---|---|
| `Button::new(rect)` | Кнопка с палитрой по умолчанию |
| `.with_colors(idle, hover, pressed)` | Своя палитра |
| `.update(&[Event]) -> bool` | Кормит события, `true` — клик в этом кадре |
| `.state()` | Текущее состояние |
| `.rect()` | Область кнопки |
| `.draw(d, &Image)` | Рисует фон и подпись по центру |

Палитра по умолчанию:

| Состояние | Цвет |
|---|---|
| `idle` | `rgb(48, 54, 70)` |
| `hover` | `rgb(78, 98, 140)` |
| `pressed` | `rgb(150, 106, 58)` |

Логика клика:

- клик происходит **по отпусканию**, а не по нажатию;
- только если курсор всё ещё над кнопкой;
- только левая кнопка мыши;
- нажатие вне кнопки не делает её `Pressed`;
- удержание и уход курсора оставляют `Pressed`, пока кнопку не отпустят;
- `FocusLost` сбрасывает состояние в `Idle`, чтобы после alt-tab кнопка не
  осталась залитой.

`draw` рисует прямоугольник фона и подпись, обе центрированные в `rect`.
Подпись сохраняет свой размер: если `rect` больше текста, остаётся поля, а не
растянутые буквы.

## `Slider`

Файл `src/ui/slider.rs`.

```rust
pub struct Slider {
    rect: Rect,
    min: f32,
    max: f32,
    step: f32,   // 0 — непрерывно
    value: f32,
    state: SliderState,
    track: Color,
    fill: Color,
    knob: Color,
    knob_held: Color,
}
```

| Состояние | Когда |
|---|---|
| `SliderState::Idle` | Курсор не над слайдером, перетаскивания нет |
| `SliderState::Hover` | Курсор над слайдером |
| `SliderState::Dragging` | Ползунок тащат |

| Метод | Что делает |
|---|---|
| `Slider::new(rect)` | Диапазон `0..1`, шаг `0`, значение `0` |
| `.with_range(min, max, step)` | Диапазон и шаг; текущее значение зажимается |
| `.with_colors(track, fill, knob, knob_held)` | Четыре цвета |
| `.update(&[Event]) -> bool` | Кормит события, `true` — значение изменилось |
| `.state()` | Текущее состояние |
| `.rect()` | Область слайдера |
| `.value()` | Текущее значение |
| `.set_value(value)` | Задать значение (зажимается и округляется к шагу) |
| `.fraction()` | Значение как `0..1`; пустой диапазон → `0` |
| `.knob_side()` | Сторона квадратного ползунка = высота дорожки |
| `.draw(d)` | Рисует дорожку, заполненную часть и ползунок |

Геометрия:

```text
knob_side = max(rect.h, 1)
travel    = max(rect.w - knob_side, 0)
knob_x    = rect.x + knob_side / 2 + fraction * travel
value_at(x) = clamp_and_snap(min + clamp((x - rect.x - knob_side/2) / travel, 0, 1) * (max - min))
```

Ползунок квадратный, потому что библиотека рисует только прямоугольники. Он
равен высоте дорожки, чтобы заполнять её от края до края; это же сокращает ход
на половину ползунка с каждой стороны.

Логика отличается от кнопки осознанно:

- значение меняется **при нажатии**, а не при отпускании: слайдер — это
  позиция, а не триггер;
- перетаскивание продолжается за пределами дорожки: иначе до крайнего
  значения нельзя было бы дотянуть одним движением;
- отпускание в любом месте заканчивает перетаскивание;
- `FocusLost` сбрасывает состояние;
- только левая кнопка мыши.

Округление к шагу:

```text
value = clamp(value, min, max)
если step <= 0: вернуть value
steps = round((value - min) / step)
вернуть clamp(min + steps * step, min, max)
```

## Как добавить виджет

1. Создайте файл в `src/ui/`, например `checkbox.rs`.
2. Опишите состояние, `new`, билдеры, `update(&[Event])`, `draw(&mut Draw)`.
3. В `draw` используйте `d.screen_space(|d| ...)`.
4. Объявите `mod checkbox;` и `pub use checkbox::{Checkbox, CheckboxState};` в
   `src/ui/mod.rs`.
5. Реэкспортируйте в `src/lib.rs`.
6. Добавьте unit-тесты на логику кликов без окна: события и `Rect` — обычные
   значения, SDL не нужен.

## Тесты

- `button.rs` — 11 тестов: наведение, клик по отпусканию, уход курсора,
  нажатие снаружи, потеря фокуса, правая кнопка, батч событий.
- `slider.rs` — тесты на старт, нажатие, крайние значения, шаг, перетаскивание,
  фокус, непрерывный режим.
- `text.rs` — 3 теста на все девять якорей и сохранение размера.

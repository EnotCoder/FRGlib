# 10. 3D и Wgpu (Опционально)

Фича `wgpu` добавляет в FRGLib поддержку современного графического API для 3D-рендеринга. В этом режиме SDL3 по-прежнему отвечает за создание окна и обработку ввода, но отрисовкой управляет `wgpu`.

**Важно:** `WgpuWindow` — это параллельный тип окна. Он не поддерживает `Draw`, `UI` и `TileMap`, так как они жестко привязаны к 2D-рендереру SDL3.

## Основные компоненты

Слой разбит на два уровня доступа:

1.  **Готовые инструменты:**
    *   `Camera3D` — перспективная камера с поддержкой орбитального вращения.
    *   `Mesh` — описание геометрии на CPU (куб, плоскость, сетка, линии).
    *   `Renderer3D` — высокоуровневый рендерер, который умеет рисовать меши, кубы и отладочные линии с освещением или без.
2.  **Сырой API (Raw API):**
    *   `Gpu` — доступ к `Device`, `Queue`, `Adapter` и конфигурации поверхности.
    *   `Frame` — доступ к текущему `CommandEncoder`, вьюхам цвета и глубины. Позволяет вставлять свои `wgpu`-проходы в общий цикл кадра.

## Жизненный цикл кадра WGPU

Цикл отличается от 2D-версии необходимостью явно начинать и завершать кадр:

```rust
loop {
    // 1. События (общие для всей библиотеки)
    for event in window.poll()? {
        if event.should_close() { return Ok(()); }
    }

    // 2. Получение кадра (может вернуть None, если окно свернуто)
    let Some(mut frame) = window.begin_frame()? else { continue };

    // 3. Подготовка рендерера
    renderer.begin(&camera);
    
    // 4. Очередь отрисовки
    renderer.draw_cube(Vec3::ZERO, Vec3::ONE, Color::RED);
    renderer.draw_grid(20, 1.0, Color::WHITE);
    
    // 5. Запись команд в энкодер кадра
    renderer.finish(&mut frame);
    
    // 6. Вывод на экран
    window.present(frame)?;
}
```

## Координаты и Математика

*   **Система координат:** Правая (Right-handed), Y направлен вверх.
*   **Математика:** Используется библиотека `glam` (версия 0.34). Основные типы (`Vec3`, `Mat4`) реэкспортированы через `frglib::gpu::glam`.
*   **Цвета:** Автоматически конвертируются из sRGB в линейное пространство для корректного освещения.

## Освещение

Стандартный шейдер (`lit.wgsl`) реализует:
*   Один направленный источник света (Directional Light).
*   Ambient-освещение (фоновое).
*   Specular-блики (Блинн-Фонг).

Для объектов без освещения (сетки, оси, отладочные линии) используйте `Material::Unlit`.

## Смешивание с сырым WGPU

Вы можете использовать `Renderer3D` для основной сцены, а затем использовать `frame.encoder` для своих проходов (например, пост-процессинга или специфических эффектов). `Renderer3D::finish` всегда очищает экран цветом фона окна, поэтому ваши проходы должны идти **после** него и использовать `LoadOp::Load`.

## Ограничения

*   **Текст:** В текущей версии (M2) текст в 3D не реализован.
*   **Текстуры:** Рендерер пока поддерживает только сплошные цвета (Vertex Colors).
*   **MacOS:** Обязательно используется `.metal_view()` внутри билдера (включено по умолчанию в `WgpuWindowBuilder`).
